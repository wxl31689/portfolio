餐厅点餐管理系统

这是一个面向餐厅堂食场景的点餐管理系统，包含微信小程序点餐端、Web 后台管理端和 Node.js 后端接口服务。用户可以在小程序中浏览菜品、加入购物车、提交订单并查看订单状态；商家可以在后台维护菜品、分类、餐桌和订单，并查看经营数据概览。

项目功能

- 小程序点餐：支持首页推荐、菜品分类浏览、购物车、下单、订单详情和我的订单。
- 后台管理：支持管理员登录、菜品管理、分类管理、餐桌管理、订单处理和数据看板。
- 后端接口：基于 Express 提供菜品、分类、订单、上传和后台管理接口。
- 数据存储：使用 MySQL 保存管理员、菜品分类、菜品、订单、订单明细和餐桌信息。
- 图片管理：支持菜品图片上传，并通过后端静态资源地址访问上传文件。

技术栈

- 前台：微信小程序原生开发
- 后台页面：HTML、CSS、JavaScript
- 服务端：Node.js、Express
- 数据库：MySQL
- 主要依赖：cors、multer、mysql2、nodemon

项目结构

```text
restaurant-order-system/
├── admin-web/              # 餐厅后台管理页面
├── miniprogram/            # 微信小程序点餐端
├── server/                 # Express 后端服务
│   ├── routes/             # 接口路由
│   ├── uploads/            # 上传的菜品图片
│   ├── app.js              # 服务入口
│   └── db.js               # MySQL 连接配置
└── restaurant_order.sql    # 数据库初始化脚本
```

运行方式

1. 创建 MySQL 数据库并导入 `restaurant_order.sql`。
2. 根据本地数据库环境修改 `server/db.js` 中的连接配置。
3. 进入 `server` 目录安装依赖并启动服务：

```bash
npm install
npm run dev
```

4. 后端默认运行在 `http://localhost:3000`。
5. 使用微信开发者工具打开 `miniprogram` 目录运行小程序。
6. 直接打开 `admin-web/login.html` 可进入后台管理页面。

项目说明

该项目覆盖了餐厅点餐业务中的核心流程：顾客在线浏览菜单并提交订单，后台实时管理菜品和订单状态，服务端统一处理数据读写和图片上传。整体结构清晰，适合作为餐饮点餐系统课程设计、毕业设计或全栈项目练习使用。
